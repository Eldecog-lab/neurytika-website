THE METHOD

01 — Evidence Ratio Classifier

Make the pattern
part of the explanation.

ERC represents evidence as combinations of discrete features, with counts and probabilities that can be inspected directly.

Numeric values are grouped into bins and categorical values become tokens. ERC evaluates combinations up to a configurable size and tracks their support across classes. These local evidence units connect a prediction to concrete patterns in the dataset.

FROM DATA TO UNDERSTANDING

02 — The Neurytika workflow

A clear path through
complex data.

The Neurytika MVP brings ERC into a web exploration workflow, connecting dataset structure, classification and local explanations.

  1. 01 / IMPORT

    Start with a CSV

    Profile columns, missing values and distributions. Select the target class.

  2. 02 / REPRESENT

    Build discrete features

    Encode numeric, categorical and boolean data as tokens for combinatorial analysis.

  3. 03 / ANALYZE

    Discover class evidence

    Configure pattern size and minimum support, then examine global patterns and evaluation metrics.

  4. 04 / EXPLAIN

    Inspect a prediction

    Explore the contributing patterns and their statistical support for an individual row.

RESEARCH & ENGINEERING

03 — Built for exploration

One idea.
Multiple directions.

A portable C core at the heart of an interpretable analytics project.

Neurytika's architecture connects the ERC engine in C, a Go backend, a web exploration interface and Python research tools. The project is in active MVP development, with a focus on CSV ingestion, classification and pattern explanations.

APPLICATION DIRECTIONS

Scientific analysis

Explore associations in tabular datasets and formulate questions around explicit feature interactions.

Transparent decision support

Investigate classification workflows where teams need to inspect the patterns contributing to a prediction.

Embedded intelligence

Explore the portability of the C engine for sensing and edge computing research.
